# fatsearch Homebrew tap

```sh
brew install fatsearch/tap/fatsearch
```

Formula `fatsearch` installs the `fats` binary. The formula is written by the release workflow of
[fatsearch/fatsearch](https://github.com/fatsearch/fatsearch) on every tag; nothing here is edited by hand.

Licensed under MIT OR Apache-2.0, like fats.
